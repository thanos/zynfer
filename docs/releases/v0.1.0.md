# zynfer v0.1.0

Apple M-series backend Stages 0–8 closed for the **tiny transformer-block
fixture**. This is not a Qwen-capable inference release.

## In scope

- Backend-neutral host types + deterministic CPU f32 oracle
- Thin Metal ObjC bridge, shared buffers, capability discovery
- Metal LLM ops differentially tested vs CPU
- Tiny-block prefill/decode with Metal-resident KV and one CB / one wait
  (`batched_resident_kv_fused`; A/B via `ZYNFER_APPLE_BLOCK=baseline`)
- Stage 5: size-gated `simdgroup_matrix`, int8 GEMV/GEMM ops, Accelerate vDSP
- Stage 7: SME/Core ML probed; both **inference** paths rejected
- Stage 8: `kv_len` ≤ 256, opt-in signposts, `peak_rss_bytes`, stress +
  dual-`Gpu` concurrency; ICB / Session int8 / fp16 Metal / extra tiny-block
  fusions rejected with reasons
- Benchmark matrix: `docs/benchmarks.md`; ledgers under `bench/results/apple-stage*.md`

## Out of scope (mapped, not silent)

| Item | Lands in |
| --- | --- |
| Qwen loader / artifact | **done (Stage 10)** |
| Full Qwen3-0.6B forward + golden logits | Stage 11 — [`docs/stages/11-qwen-forward.md`](stages/11-qwen-forward.md) |
| Tokenizer / sampling / TTFT | Stage 12 |

| Tokenizer / sampling / real TTFT · tok/s | Stage 12 |
| Qwen-scale fusion / ICB revisit | Stage 16 |
